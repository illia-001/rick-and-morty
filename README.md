# Rick and Morty Explorer 🌌

A project built on **Next.js 14+** that uses [The Rick and Morty API](https://rickandmortyapi.com/) to display a database of characters, locations, and episodes from the animated series.

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** CSS Modules / Tailwind

## Features

- **Character Catalog:** Browse a list of all characters with pagination.
- **Advanced Filtering:** Search by name, status (Alive, Dead, Unknown), gender, and species.
- **Detailed Pages:** Dedicated pages for each character, episode, and location.
- **Server-Side Rendering (SSR):** Optimized server-side data loading for better SEO and performance.
- **Responsive Design:** Fully responsive for mobile devices and desktops.

## Installation and Setup

1. **Clone the repository:**
   ```
   git clone [https://github.com/illia-001/rick-and-morty.git](https://github.com/illia-001/rick-and-morty.git)
   cd rick-and-morty
   ```
   ```
   npm install
   # or
   yarn install
   npm run dev
   ```
Open http://localhost:3000 in your browser.
